# Audit (run before calling it done)

Work like a critic who has read the article. Score 0–2. Evidence in one sentence each.

## Scorecard

| Axis | 0 | 2 |
|---|---|---|
| Identity | Feature list / awareness ad | Using it would make someone feel they belong |
| Decided | Extra colors, type, or effects mid-piece | 3 colors, 2 types, same field, same music/motion family |
| Stills | Motion is carrying a weak layout | Mid-hold / above-the-fold still works as a poster |
| One idea | Two jobs in one shot or section | Split until one idea remains |
| Breathe | Packed, bg interrupts hero | Dead-quiet field, hero centered, space around it |
| Type system | Mixed families across title / UI / legal | One system everywhere |
| Contrast | Bright-on-bright or loud field | Color lives on product/UI only |
| Motion | Linear, same tempo, hard cuts for no reason | Eased, overlapped, adaptive rhythm, cuts earned |
| Audio | Extra SFX, off-band music, rap default | BPM band locked, listen-pass cuts anything off |
| Cheap tells | Glow, particles, bounce, slogan salad | Restraint. Deletion left a mark |

Ship only if stills + identity + decided are all 2, or list the debt in the open.

## Rituals (do not skip)

1. Still pass — export or screenshot mid-hold of every shot/section. Delete or redesign any frame that is not a poster.
2. Identity pass — mute the logo. Does the piece still feel like a way to identify, or only a spec sheet?
3. Listen / motion pass — play once. Remove anything loud, cute, or not helping engagement or understanding.
4. Belonging pass — mark each transition with the shared object, color, or axis. If none, it is a cheap cut.

## Cut questions (from the article)

- Was this done on accident?
- Does this font / background / music / color have a purpose?
- Does this make the brand feel less premium?
- Are we showing everything in one frame?
- Does the next scene feel like it belongs there?
- After listening, what feels off?
