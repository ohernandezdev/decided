# Cold-agent fails

What a subagent produces if it only skimmed SKILL.md or skipped principles.md.

| They ship | Why it fails | Fix |
|---|---|---|
| Feature grid hero | Awareness, not belonging | One job sentence. Product + one line |
| Purple mesh + glass cards | Costume, not constitution | Void field, color on product |
| 4 button colors | Not decided | One accent |
| Inter + Geist + serif footer | Type system broken | One family, 2 weights |
| Autoplay bg video | Field interrupts hero | Kill the video |
| Framer fade on every block | No adaptive rhythm | Hero slow, proof lifts, close holds |
| Spring + bounce logo | Cheap motion | Damped settle, no spin |
| Invented “10M users” | Lie | Delete |
| Code first | Skipped stills | Constitution → still → code |
| New BRIEF.md | Pollutes every project | Infer, do not write the file |

If your draft matches a row, it is not done.
