# Improve an existing site

Treat the current site as a cut. Premium usually means less.

## 1. Capture

- Live URL and/or repo
- Homepage + 2 interior templates at 1440 and 390
- Current colors, type, motion, and voice (list what is actually used, not what the brand PDF claims)

If only a URL exists, inspect computed styles and screenshots before proposing tokens.

## 2. Scorecard (0–2 each)

| Axis | 0 | 2 |
|---|---|---|
| Intention | Mixed type, many colors, no rules | Locked 3-color / 2-type system |
| Space | Packed, competing focals | One idea per view, real emptiness |
| Contrast | Bright-on-bright, weak product | Quiet field, loud hero |
| Type | 3+ families, tight tracking, tiny body | 1–2 families, display tracking, readable body |
| Motion | Linear, bounce, everything animates | Eased, sparse, holds |
| Copy | Hype, fake metrics, twin CTAs | Specific, one CTA |
| Craft | Inconsistent radius/shadow/icon | One constitution everywhere |
| Cheap tells | Glow, gradients-as-identity, stock collage | Product on void |

Write the score and one sentence of evidence per axis.

## 3. Cut list first

Delete before you add:

- Extra typefaces and leftover brand colors
- Background videos or particles that hide a weak hero
- Carousels that auto-rotate five ideas
- Duplicate CTAs, newsletter walls on first view, chat widgets on the hero
- Box-shadow stacks, glassmorphism, neon borders
- Scroll stories that animate every heading

Each cut names the file/section and why it cheapens the brand.

## 4. Token patch

Propose a replacement constitution:

- Keep colors that already feel owned if they can be reduced to 3
- Replace type only if the current stack cannot look quiet-premium
- Map old classes to new tokens so the patch is mechanical

Do not sneak a fourth accent in buttons vs links vs charts. Charts use ink + one accent.

## 5. Apply in order

1. Global tokens and typography
2. Homepage hero (the poster)
3. Homepage remaining sections (split packed sections)
4. Shared nav/footer
5. One interior template as proof the system travels
6. Motion pass last

Stop and show stills after the hero. If the hero still looks cheap, do not restyle interior pages yet.

## 6. Re-audit

- Same scorecard
- Before/after stills at 1440 and 390
- List residual debt (pages not patched)

Do not call it done because a gradient was swapped. Done = constitution holds on every patched surface.
