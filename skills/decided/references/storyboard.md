# Storyboard

Write stills first, then the shot list, then any component. One row = one idea. Key object in the center. Background never interrupts it.

The deliverable before code is a set of mid-hold frames (Figma or static exports), not a list of animation ideas.

## Default arc (15–30s)

| Beat | Time | Job |
|---|---|---|
| Hook | 0–3s | Product visible. One image that feels premium |
| Promise | 3–7s | What using it makes you |
| Proof | 7–18s | 2–4 feature shots, one idea each |
| Resolve | last 3–5s | Hero product + mark. Hold. Do not rush the logo |

## Shot-list columns

- `#`
- `start–end` (seconds and frames at 30fps)
- `idea` (one sentence, no compound ideas)
- `hero` (what sits in the center)
- `field` (bg color / emptiness)
- `type` (exact string, size, weight — or none)
- `motion` (enter / settle / exit)
- `audio` (music energy + SFX or silence)
- `cut-test` (would the still frame already look expensive?)

## Shot rules

- If two ideas are in one shot, split the shot
- Hold long enough to read. Display type needs ~1.5–2.5s on screen
- Transition should feel like the next shot belongs there (match move, match color, match scale)
- End on a still that could be a poster

## Example row

`3 | 4.0–7.0s / f120–210 | Wallet opens to a clean home | phone UI centered | #0A0A0A void | none | scale 1.04→1.00 ease, UI cards stagger 4f | 90–110 BPM bed, soft whoosh under 8dB | yes`
