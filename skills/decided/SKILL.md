# decided

Design first. Code second. A cold agent that skips the next block will ship the Apple costume and fail this skill.

## Cold-agent gate (do this before any file write)

1. Read `references/principles.md` in full. Then `references/audit.md`.
2. Pick one mode. If the user pasted a URL or an existing repo to “make premium,” that is Improve site. If they want a clip, Film. Else New site.
3. Print a 6-line constitution and stop if tokens are still invented from taste rather than repo/assets.
4. Only then design stills. Only then code.

If you did not read `principles.md`, you are not running this skill.

Default constitution when the repo has no brand file and the user gave no colors

- Field `#0A0A0A` if the product is light, `#F5F5F7` if the product is dark
- Ink is the opposite
- Accent taken from the product or UI. Never a second accent
- Type — the repo’s existing sans if it is a real family, else Inter, 2 weights
- Motion curve `cubic-bezier(0.4, 0.0, 0.2, 1)`, hero 400–800ms
- Music band 90–110 unless the brief is heritage (60–80) or kinetic (115–123)

Do not invent a palette “that feels Apple.” Do not invent UI copy, metrics, logos, or screenshots. Missing product shots stay labeled placeholders on void.

## Fail closed

These outputs mean the skill was ignored. Delete and redo.

- Black + blur + spring + 6 features above the fold
- Mesh gradient or glow as identity
- Fourth color on hover, chart, or badge
- Third typeface in the footer or captions
- “Learn more” as the primary CTA
- Fake testimonials, user counts, press row
- Same fade-up on every section
- Linear or bounce on the product
- Rap / trailer bed on a quiet brief
- Hard cut or instant route with no shared object, color, or axis
- Motion started before a mid-hold still exists
- Code in the first message

## Shared rules

Not awareness. Belonging. People who already know the brand should feel special for choosing it.

- Every type, field, music, and color choice needs a purpose or it goes
- 3 colors, 2 typefaces, same field, same motion family — so it feels decided
- One shot / section = one idea. Do not show everything
- Hero in the center. Field dead quiet. Color lives on the product or UI
- Never bright-on-bright
- Titles, UI, and legal share the type system
- Ease and overlap. Holds are luxury. Adaptive rhythm
- After motion or mix, delete anything that does not help understanding or engagement

## Modes

Film — stills + shot list, product by 3s, then Remotion only if the stack is already Remotion/JS. Else editor-ready spec. Audit still / identity / listen / belonging.

New site — tokens in the project theme file, homepage as shot list, stills at 1440 and 390, then build. No component-library tour first.

Improve — capture live styles. Score. Cut list first. Token patch. Hero only. Stop for stills. Interior after the hero is a poster.

## Done

Run `references/audit.md`. Ship only if identity, decided, and stills score 2, or list the debt in the open.
