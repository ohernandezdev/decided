# decided

Premium does not come from more effects.

It comes from rules so strict the audience feels you **decided** it had to be that way.

`decided` is a Claude Code plugin. It turns that idea into a system anyone can run on a site or a product film — new work or a cut of something that already exists.

Not a costume. Not black + SF Pro + spring. A constitution.

## Install

```bash
claude plugin marketplace add ohernandezdev/decided
claude plugin install decided@decided
```

Then `/decided:site`, `/decided:film`, `/decided:audit`, or `/decided:lock`.
