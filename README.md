# decided

Not the Apple costume. The rules.

A Claude Code plugin that makes sites and product films feel expensive because nothing is accidental.

```bash
claude plugin marketplace add ohernandezdev/decided
claude plugin install decided@decided
```

```
/decided:site
/decided:film
/decided:audit
/decided:lock
```

3 colors. 2 typefaces. One idea per frame. If the still is not a poster, do not animate it.

Framework from [Leo](https://x.com/leomeethewoo/status/2103529310208606701). MIT.
