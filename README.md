# decided

Premium does not come from more effects.

It comes from rules so strict the audience feels you **decided** it had to be that way.

`decided` is a Claude Code plugin. Sites and product films. Open source.

Not a costume. Not black background + SF Pro + spring. A constitution.

## Why this exists

Leo wrote the framework. Models already know the Apple look. They do not keep the rules.

This plugin is the rules.

## Install

```bash
claude plugin marketplace add ohernandezdev/decided
claude plugin install decided@decided
```

| Kind | Name | Use |
|---|---|---|
| Skill | decided | Auto on film, site, redesign |
| Command | /decided:film | Product film, stills first |
| Command | /decided:site | New marketing site |
| Command | /decided:audit | Cut an existing site or film |
| Command | /decided:lock | Constitution only, no code |
| Agent | stills-critic | Poster test |
| Agent | identity-critic | Belonging vs feature dump |
